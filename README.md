# Fault Detector

<p align="justify">
Determina faltas de futbol mediante la incorporación de clips visualizados en un reproductor de video, adecua una red neuronal extraída de hugging fase, adicionalmente permite insertar URLS para generar un fragmento de video a partir de una página haciendo uso   
del navegador Chrome, con la finalidad de evaluar fragmentos deseados en repeticiones de partidos en tiempo real. 

Fue creado un dataset para el reentrenamiento del modelo.
</p>

## **Modelo Empleado**

https://huggingface.co/keras-io/video-classification-cnn-rnn
