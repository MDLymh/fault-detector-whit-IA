# Fault Detector

<p align="justify">

Determina faltas de futbol mediante la incorporación de clips visualizados en un reproductor de video, adecua una red neuronal extraída de hugging fase, adicionalmente permite insertar URLS para generar un fragmento de video a partir de una página haciendo uso del navegador Chrome, con la finalidad de evaluar fragmentos deseados en repeticiones de partidos en tiempo real. 

</p>

## **Modelo Empleado**

https://huggingface.co/keras-io/video-classification-cnn-rnn

## **Características**

- ![Completado](https://img.shields.io/badge/Completado-%23C20000?style=flat-square) Detector Faltas
- ![Completado](https://img.shields.io/badge/Completado-%23C20000?style=flat-square) Reproductor Video
-	![Completado](https://img.shields.io/badge/Completado-%23C20000?style=flat-square) Graba Navegador 60 Segundos (Generar Clip)
-	![Completado](https://img.shields.io/badge/Completado-%23C20000?style=flat-square) Retroalimentación Texto y Gráficas
